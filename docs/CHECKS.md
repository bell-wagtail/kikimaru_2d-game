# 変更後の検証

前提：[環境準備](SETUP.md)が完了していること。検証結果はここに蓄積せず、[STATUS](STATUS.md)に記録します。

## 自動検証

プロジェクトルートで実行します。コマンド定義は [package.json](../package.json) の `scripts` が正本です。

```powershell
mise exec -- npm.cmd --cache .npm-cache run check
mise exec -- npm.cmd --cache .npm-cache test
mise exec -- npm.cmd --cache .npm-cache run build
```

- `check`：TypeScriptの型チェック。
- `test`：入力・移動・背景の反復位置・座標補正・障害物定義と接触・文字マップの変換・穴と床区間・床の着地条件・アイテム定義・効果時間・2段ジャンプ・取得／終了通知・終了前の明滅周期・スコアの配点と上下限・クイズの全選択肢順序と正解対応・一巡内の重複防止と問題数の増減・一巡の境目の連続重複防止・出題履歴の初期化と独立性・回答の多重処理防止。ブラウザ描画やPhaserの実際の物理動作を保証するテストではありません。
- `build`：型チェックを含む配信用ファイルの生成。出力先・消去方針は [vite.config.js](../vite.config.js) を参照。

変更内容に必要な検証だけを選びます。`build`を実行する場合、直前の`check`は省略できます。
Phaserのチャンクサイズ警告が出る場合は、ビルドの終了結果と区別して扱ってください。
現在は出力先を自動消去しない設定なので、公開前には古い生成ファイルの扱いを確認します。

## 手動確認

[起動・操作手順](RUN.md)に従ってデモを起動し、変更の影響がある項目を確認します。

- 左右移動・キーを離したときの停止・左右同時押し・画面端に相当する距離を越えても移動を続けられること。
- 背景と地面の反復境界に隙間が出ず、折り返しや長距離移動で背景・キャラクターが急に飛ばないこと。
- 地上からのジャンプ、着地、移動しながらのジャンプ。
- 左右どちらのShiftでも徐々に加速し、離すと徐々に徒歩速度に戻ること。減速途中の再押下で残った速度から加速すること。Shift単独では助走をためられず、地上で左右入力を解除・相殺すると停止して助走がリセットされること。
- 徒歩ジャンプ中にShiftを押しても加速せず、ダッシュジャンプ中に離しても減速しないこと。加速途中・減速途中のジャンプも踏み切り速度を保ち、着地から現在のShift状態に応じて加減速を再開すること。高さ・滞空時間が変わらず、飛距離だけが踏み切り速度に応じて伸び、背景が飛ばないこと。
- ダッシュ中のリセット・フォーカス喪失後に加速状態が残らないこと。
- 徒歩・加速途中・最高速度のそれぞれで、岩の左右の側面に当たると停止し、押し続けてもめり込まないこと。逆方向へ離れられること。
- 岩上への着地・静止・再ジャンプ・端からの落下・飛び越え。壁際からジャンプすると岩より高くなった時点で横に進めること。
- 文字マップの配置に従い、低い岩から中段・上段へジャンプで登れること。横に並ぶ岩の継ぎ目で停止・落下しないこと。マス寸法を変えると位置・表示・当たり判定が一緒に変わること。
- `o` のお茶・`j` のえびに触れると一度だけ取得し、表示が消えること。お茶で地上移動がShiftなしで即最高速度になり、停止後の再開も即最高速度、空中取得では踏切速度を維持して着地から即最高速度になること。えびで空中ジャンプ1回が使えること。併用・時間切れ・別アイテムによる時間更新、リセットと落下リスポーンで能力解除とアイテム復元を確認すること。
- お茶は緑、えびは赤の円形発光で、併用中は二重に光ること。終了前は効果ごとに明滅が速くなり、再取得では通常の周期へ戻り、終了で光が消えること。取得・終了の文字が短時間だけ表示され、通知が重なっても読めること。反転・ジャンプ・座標補正後も光が追従し、フォーカス喪失では演出時間が止まり、リセット・リスポーン・シーン再起動では光と通知が消えること。
- 座標補正後も岩の表示と衝突位置が一致し、戻ってきた際に同じ場所で衝突すること。空中・岩上・座標補正後のリセットでプレイヤーと岩が開始位置へ戻ること。
- 最下行の空きマスが元の地面と同じ草・土の縁を持つ穴になり、周囲の地面に素材の切断線が出ないこと。徒歩・加速途中・最高速度で左右から落下でき、ジャンプで対岸へ着地できること。落下中に左右の壁へ当たると横移動だけが止まり、押し続けても床の下へ抜けず、下へ落ち続けること。反対方向へ壁から離れられ、床面へ持ち上がらず、えび未取得では空中ジャンプもできないこと。画面下への落下と落下途中のリセットで、位置・入力・助走・背景・カメラが開始状態に戻ること。
- 穴の上の岩にも着地・再ジャンプできること。座標補正後も穴の表示・床の衝突位置が一致し、穴に再訪しても落下・リスポーンできること。
- 押しっぱなしで自動連続ジャンプしないこと、えび未取得・時間切れでは空中ジャンプができず、効果中でも3段目は使えないこと。着地で回数が戻り、歩いて足場から落ちた場合や空中取得後にも1回使えること。
- 「まんなかに戻る」で背景・地面・カメラも戻ることと、別タブ・別ウィンドウへ移った際の入力解除。
- タッチ対応を変更した場合は、移動とジャンプの同時操作をスマホ実機で確認。
- `F` の魚・`M` のみかん・`S` のいちごの一度だけ取得と種類別配点、取得通知、能力時間・発光への影響がないこと。`Q` の4択と正誤・点数変化・再開ボタン、未回答のキャンセル拒否、クイズ中の物理・能力時間・演出停止、フォーカス復帰でも停止を保持すること。スコアの上下限、手動リセット・落下・再起動でのスコア初期化と魚／果物／マーカーの復元、補正後の表示位置での取得・接触も確認。

## Phaser上の横スクロール結合テスト

通常移動に加え、Shift入力による連続加減速・減速途中の再加速・左右Shift併用・踏み切り時の速度維持・着地後の加減速・高さと滞空時間の一致・飛距離の速度比例・状態表示と、ダッシュでの長距離移動・座標補正・フォーカス喪失・リセットも検証します。

[obstacles.browser.js](../tests/obstacles.browser.js) の障害物検証も同じページから実行します。徒歩・加速途中・最高速度で左右からの側面停止、岩上の着地・静止・再ジャンプ・歩いて降りる動作、飛び越えを確認します。左右の座標補正境界に岩を置くステージへ再起動し、空中での補正から岩上へ着地、補正後の衝突、複数補正後の再訪、物理ボディと衝突検索位置の一致、各状態でのリセット、再起動時の重複がないことも確認します。背景の長距離検証は障害物のないステージで行います。

[stageMap.browser.js](../tests/stageMap.browser.js) は [専用の階段マップ](../tests/fixtures/stairs.txt) から生成したステージを検証します。開始位置からの歩行→低い岩→中段→横5個の上段への連続ジャンプ、上段の左右歩行、tea取得、左右の座標補正とリセット、マス寸法変更、再起動時の重複を確認します。実際のステージを編集しても、この回帰テストの配置は変わりません。

[items.browser.js](../tests/items.browser.js) は同じページからアイテム専用ステージを検証します。両素材の表示・一度だけの取得・お茶の地上取得／移動再開で即最高速度・2段ジャンプ・併用・時間切れ・空中取得と時間切れでの速度維持／着地で即最高速度・押しっぱなしと3段目の拒否・能力有効中の岩と穴の衝突・手動リセット・落下リスポーン・フォーカス喪失・左右と複数回の座標補正後の取得・再訪・マス寸法変更・再起動・既存の座標指定を確認します。

[feedback.browser.js](../tests/feedback.browser.js) は同じページから円形発光・取得と終了の通知を検証します。緑と赤の光・二重表示・キャラクターの後ろへの描画・通知の画面固定・通知の自動消去・残り時間に応じた周期短縮・再取得・効果ごとの消去・左右反転とジャンプと座標補正への追従・フォーカス停止・リセットとリスポーンと再起動での消去・表示とテクスチャとColliderが増えないことを確認します。

[speedLines.browser.js](../tests/speedLines.browser.js) は同じページからスピード線を検証します。徒歩・Shift単独では表示しないこと、実速度による加減速で描画される線の長さ・本数・濃さが変わること、空中の速度維持と停止・左右方向転換・左右の座標補正に追従することを確認します。お茶の自動ダッシュ、壁への衝突停止、フォーカス喪失、手動リセット、落下リスポーン、再起動と描画数・Colliderも確認します。

[ground.browser.js](../tests/ground.browser.js) は穴のあるテストステージを検証します。徒歩・加速途中・最高速度で左右から落下して壁へ衝突・停止を維持し、下へ落ちてリスポーンする動作、穴の中で方向転換して両方の壁で停止、ジャンプで対岸へ着地、入力と助走の解除、落下中の空中ジャンプ拒否・手動リセット、体幅より狭い穴の通過、穴を広げても土壁の厚さと物理境界を保つこと、外縁の土が元の地面と同色で狭い穴でも地面へはみ出さないこと、穴の上の岩への着地・再ジャンプ、左右の座標補正と複数補正後の再訪、床の衝突検索位置、リスポーン・再起動時のオブジェクト数を確認します。

[RUN](RUN.md)に従って開発サーバーを起動し、表示されたURLのパスを `/@fs/<プロジェクトの絶対パス>/tests/scrolling.browser.html` にします。Windowsのパス区切りは `/` を使用します。このページは開発サーバー専用で、配信用ビルドには含みません。

「結合テストを実行」で現行の `WalkScene` を使い、左右の長距離移動、空中での座標補正、着地、停止、フォーカス喪失、リセット、別ステージ定義での再起動を検証します。結果の最終行が `PASS 全項目完了` になることを確認してください。URL末尾に `?canvas` を付けるとCanvas描画、それ以外はWebGL描画です。

「右へ4秒進める」「左へ4秒進める」で移動後の反復境界、「穴の手前を表示」で現行ステージの最初の穴を目視できます。テストは物理更新を高速に進めるため、実時間の長時間プレイや端末性能の測定ではありません。

「お茶の発光を見る」「えびの発光を見る」「両方の発光を見る」「終了通知を見る」で、専用ステージの演出を時間停止した状態で目視できます。現行マップは変更しません。「結合テストを実行」で通常の検証へ戻ります。

「加速途中の線を見る」「最高速度の線を見る」「発光とスピード線を見る」で、専用ステージのスピード線を時間停止して比較できます。線が速さに応じて長く・多くなることと、円形発光と重なったときの見やすさを確認します。

[scoreQuiz.browser.js](../tests/scoreQuiz.browser.js) も同じ結合テストへ組み込んでいます。[専用マップ](../tests/fixtures/score-quiz.txt) を使い、能力付きアイテム・魚・みかん・いちごの配点と取得通知・一度だけ取得・上下限・果物取得時の能力時間と発光の維持・クイズ4択と正誤・多重回答防止・回答後の明示的な再開・未回答のキャンセル拒否・空中での位置と速度保持・能力時間と全演出の停止・フォーカス復帰・リセットと落下と再起動での復元・左右と複数補正後の表示位置での接触・重なるマーカーの個別出題を確認します。現行マップは変更しません。

問題数より多いマーカーを重ねた専用ステージで、各一巡の全問出題と重複防止、使い切った後の再出題、一巡の境目の連続重複防止も確認します。手動リセット・落下リスポーン・シーン再起動・別ステージ開始で出題履歴が初期化されることを検証します。

「クイズを見る」で専用ステージの4択を表示できます。回答と結果表示、一文豆知識、再開ボタンを目視確認できます。豆知識は正解・不正解とも現在の問題と一致し、未回答や次の問題の出題時には表示されないことも結合テストで確認します。現行マップへ試験配置は追加しません。

「果物を見る」で、みかん・いちごを配置した専用ステージを表示します。右へ進んで取得・通知・スコアを確認でき、「まんなかに戻る」で果物も復元します。現行マップは変更しません。

[trailStage.browser.js](../tests/trailStage.browser.js) は [寄り道マップ](../src/stage-maps/tea-river-trail.txt) を開始位置から入力で移動して検証します。地上ジャンプだけで穴と低い橋を越え、高台の下を歩いて果物と平地のクイズを取得するルート、えびの2段ジャンプで高台へ登って魚・いちごを取得し、中盤のクイズ前に地面へ着地するルートを確認します。クイズ接触時の接地・全問の重複防止・得点、左右の座標補正後の表示と衝突検索と取得位置、リセット・再起動での復元と表示・物理ボディ数も確認します。

「寄り道ステージで遊ぶ」で新しい配置を開始位置から試せます。「高台の手前から遊ぶ」はえびの手前を表示して通常操作を再開します。どちらも「まんなかに戻る」で開始位置へ戻り、能力・スコア・出題履歴とアイテムを初期化します。ユーザー編集済みの現行マップは変更しません。

## 配信用ビルドの表示

ビルド結果を確認するときは、`build`の成功後に次を実行し、表示されるURLを開きます。これは公開操作ではありません。

```powershell
mise exec -- npm.cmd --cache .npm-cache run preview
```
