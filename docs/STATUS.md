## 左右に移動し続けられるおさんぽデモ

Phaser＋TypeScript＋Viteで、左右移動・ジャンプに加えて、カメラが横方向へ追従する反復背景を実装しました。左右の画面端による移動制限はありません。左右反転、腕・足のアニメーション、地面への着地、画面操作ボタンを維持しています。

- [反復用背景](../src/kikimaru-assets/assets/backgrounds/tea_river_repeat_x.png) を採用。背景と地面をTileSpriteで反復し、遠景は地面よりゆっくり動きます。
- 読み込み時に背景の左右端を小幅でなめらかに重ね、境界の色差を抑えます。元画像は上書きしていません。
- 反復位置を一周期内に保ち、一定距離ごとに物理座標を移し直して長距離移動での数値の増大を抑えます。描画オブジェクトは移動距離に応じて増えません。
- 「まんなかに戻る」と穴への落下後のリスポーンで、キャラクター・障害物・穴・背景・地面・カメラを開始状態に戻します。
- [stages.ts](../src/stages.ts) から背景キー・移動倍率・継ぎ目の重ね幅を指定できます。シーン開始時のステージ指定にも対応。追加方法は [素材README](../src/kikimaru-assets/README.md) に記載しています。

ステージ選択画面・クリアによる次ステージへの進行は未実装です。依存関係・環境設定の変更はありません。

## 固定障害物

2026-10-01に、既存の [岩画像](../src/kikimaru-assets/assets/props/rock.png) を使った固定障害物を実装しました。開始位置の左右に低い岩があり、右側は岩から順に高い段へ登れる配置です。

- 横から当たると停止し、押し続けてもめり込まず、反対方向へ離れられます。壁で停止すると地上の助走をリセットします。壁際からジャンプすると上面より高くなった時点で横へ進めます。
- 岩の上へ着地・静止でき、再ジャンプと歩いて降りる操作もできます。適切な踏切位置から一回のジャンプで飛び越えられます。
- [stages.ts](../src/stages.ts) の `obstacles` 配列から種類・左上座標・幅・高さを指定できます。現行ステージでは文字マップからこの配列を生成します。現在の種類は `rock` のみ。省略・空配列なら配置しません。負のX座標にも対応し、背景とは別に固定配置します。指定寸法の矩形当たり判定なので、岩の輪郭の斜面に沿った判定ではありません。
- 表示・Phaserの固定ボディ・衝突検索位置を [FixedObstacles.ts](../src/FixedObstacles.ts) にまとめ、プレイヤーと同じ座標補正を適用します。元のステージ座標と累積補正量を分けて管理し、リセットでは補正量を戻して定義位置へ再配置します。移動距離でオブジェクトは増えません。

速度アップアイテム・敵・ダメージ・スコアは実装していません。お茶の画像は仮表示のみで、取得・効果はありません。キャラクター表示の分離も今回の変更には含めていません。

## 文字マップによる配置

- [tea-river.txt](../src/stage-maps/tea-river.txt) を編集すると配置を変えられます。最下行の `=` は床、`.` / 半角空白は穴です。それより上の行では `.` / 半角空白は空き、`x` は岩1個、`o` はお茶の仮表示です。`xxxxx` は5個の岩として生成します。全行の文字数をそろえます。Windowsの改行にも対応しています。
- [stages.ts](../src/stages.ts) の `STAGE_MAP_GRID` にマス幅・高さ・原点をまとめています。幅・高さを変えると、配置位置・岩の表示寸法・当たり判定も一緒に変わります。ステージごとに別の設定を渡すこともできます。座標を直接指定する既存の形式も維持しています。
- 右側は低い岩から順に高い岩へジャンプし、横5個の上段へ登る配置です。上段の岩の継ぎ目を左右に歩けます。ユーザーが編集した岩・お茶の配置を維持し、床の行だけに確認用の穴を追加しました。岩は空中でも固定され、上の岩を支える地形は自動生成しません。
- `o` は [tea.png](../src/kikimaru-assets/assets/props/tea.png) をマス内へ縦横比を保って表示します。衝突・取得・速度変化はありません。岩と同じ座標補正を適用し、リセットでは元の位置に戻します。
- 編集手順と制約は [STAGES](STAGES.md) に記載。マップの左右端はゲームの移動端にならず、配置は反復しません。プレイヤーの開始位置は従来どおりです。依存関係・環境設定は変更していません。

## 床と穴・落下時のリスポーン

- 最下行の連続した空きマスを穴として読み取り、マス幅に応じた幅で表示します。元の地面と穴の描画を [groundTextures.ts](../src/groundTextures.ts) にまとめ、同じ土・草・少量の模様の色を使った縁と土壁から、穴の内側へ暗くします。石・根・強い陰影のあるPNGを周囲の地面へ重ねる方式をやめ、描画を穴の範囲内に収めて外周の切断線をなくしました。左右の土壁は厚さを保ち、中央だけを穴の幅に合わせます。非常に狭い穴では土壁を縮めて収めます。色・草の帯・土壁の厚さの正本は同ファイルの `GROUND_APPEARANCE` です。以前制作した [穴専用PNG](../src/kikimaru-assets/assets/terrain/pit.png) とmanifest・[制作記録](../src/kikimaru-assets/GENERATION_PROMPTS.md) は保持していますが、ゲームでは読み込みません。背景全体は従来の反復素材です。穴以外とマップの外側には床が続きます。
- 画面全体の下端による接地を、穴を除く区間の固定床ボディへ変更しました。落下中に左右の穴の壁へ当たると横移動が止まり、そのまま下へ落ち続けます。押し続けても床の下へ抜けず、反対方向へ壁から離れられます。上面への着地条件は別に判定し、床面より下のプレイヤーを壁際で床上へ持ち上げません。穴の上の岩は引き続き固定足場です。
- 画面下へ落ち切ったら従来の開始位置へリスポーンし、入力・助走・障害物・仮表示・穴・床・反復位置・カメラを開始状態に戻します。落下中の手動リセットも可能です。Goal・GameOver・残機は追加していません。
- [StageGround.ts](../src/StageGround.ts) が穴の表示・床ボディ・座標補正を管理します。プレイヤーと同じ補正量を適用し、補正時に床の衝突検索位置も更新します。床ボディを再利用するため、長距離移動やリスポーンで表示・ボディは増えません。
- `holes` 配列による直接指定にも対応。省略・空配列なら全面が床です。体幅より狭い穴はまたげるため、現行のマス設定では落下させる穴に `..` 以上を使います。開始地点の足元には床を置いてください。編集方法・数値の正本は [STAGES](STAGES.md) を参照。
