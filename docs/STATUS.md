## 左右に移動し続けられるおさんぽデモ

Phaser＋TypeScript＋Viteで、左右移動・ジャンプに加えて、カメラが横方向へ追従する反復背景を実装しました。左右の画面端による移動制限はありません。左右反転、腕・足のアニメーション、地面への着地、画面操作ボタンを維持しています。

- [反復用背景](../src/kikimaru-assets/assets/backgrounds/tea_river_repeat_x.png) を採用。背景と地面をTileSpriteで反復し、遠景は地面よりゆっくり動きます。
- 読み込み時に背景の左右端を小幅でなめらかに重ね、境界の色差を抑えます。元画像は上書きしていません。
- 反復位置を一周期内に保ち、一定距離ごとに物理座標を移し直して長距離移動での数値の増大を抑えます。描画オブジェクトは移動距離に応じて増えません。
- 「まんなかに戻る」でキャラクター・背景・地面・カメラを開始状態に戻します。
- [stages.ts](../src/stages.ts) から背景キー・移動倍率・継ぎ目の重ね幅を指定できます。シーン開始時のステージ指定にも対応。追加方法は [素材README](../src/kikimaru-assets/README.md) に記載しています。

ステージ選択画面・クリアによる次ステージへの進行は未実装です。依存関係・環境設定の変更はありません。

## 確認状況

- 2026-09-30：Shiftダッシュを連続した加減速に変更。地上で左右移動しながらShiftを押すと一定の割合で最高速度へ近づき、離すと徒歩速度へ減速します。途中で押し直すと残った速度から再加速します。操作感の調整として加速・減速の所要時間を短縮済みです。加速・減速時間と速度の正本は [movement.ts](../src/movement.ts) の `PLAYER`。
- ジャンプ中は加速途中・減速途中を含めて踏み切り時の速度を維持し、空中のShift操作では加減速しません。着地から現在のShift状態で加減速を再開します。ジャンプの上向き初速と重力は一定で、高さは横速度に依存しません。同じ高さへの着地・同じ方向への移動なら飛距離は横速度に比例します。歩行アニメーションも現在の速度に応じて連続的に変わります。
- 空中の左右操作による停止・方向転換は従来どおり可能です。地上で移動入力を解除・相殺するか壁で停止すると助走をリセットし、Shift単独では助走をためられません。フォーカス喪失では入力を解除して停止し、地上では助走も解除します。空中でフォーカスを失った場合は再開後も踏み切り速度を保持します。「まんなかに戻る」とシーン再起動では保持速度もリセットします。
- ダッシュはキーボード操作のみ。タッチ専用のダッシュボタンは未実装です。
- 2026-10-01確認：加減速時間の短縮後も、mise環境で18テストと型チェックを含むビルドが成功。加減速時間、減速途中の再加速、更新頻度によらない加速、左右移動、踏み切り速度保持、リセットを検証しました。Phaserチャンクサイズの既存警告は残っています。
- 加減速時間を短縮する前のWebGL / Canvas結合テストは両方とも全項目成功。連続加減速と再加速、徒歩・加速途中・最高速度での高さと滞空時間の一致、飛距離の速度比例、空中のShift操作、着地後の加減速、通常／ダッシュ各左右200秒相当の移動、座標補正中のジャンプと着地、フォーカス喪失・リセット、ステージ再起動を確認しました。前回未確認だった踏み切り速度保持のブラウザ検証も完了しています。時間短縮後はテストページの助走時間と期待値を更新済みですが、ブラウザでの再実行は省略しています。
- 2026-09-29の背景実装時は、mise環境で10テストとビルドが成功しています。
- Codex内蔵ブラウザのWebGL / Canvas両方で、現行 `WalkScene` を使った結合テストを実行。左右それぞれ200秒相当の物理更新、反復位置の連続性、描画数が一定であること、複数回の座標補正、補正中のジャンプと着地、停止、左右同時入力、フォーカス喪失・復帰、リセット、別ステージ定義での再起動を確認しました。
- 通常画面の表示と、移動後に画面中央付近を通る背景境界を目視確認。空白の隙間や明瞭な縦の切断線は見られませんでした。
- 結合テストの再実行方法は [CHECKS](CHECKS.md) を参照。高速な物理更新による検証で、実時間の長時間プレイ・端末性能の測定ではありません。

### 速度アップアイテム（別セッション向け・未実装）

アイテムは今回実装していません。将来は最高速度の引き上げや、移動中に最高速度を維持する効果を追加する想定です。ジャンプ処理でアイテムの種類を判定したり、飛距離へ直接倍率を掛けたりせず、アイテム効果は移動速度側へ反映します。跳躍距離はその結果の実際の踏み切り速度から自然に決まり、ジャンプの高さは一定のままにします。効果時間、倍率、取得・配置方法、停止時や空中での取得時の扱いは次セッションで決めます。現時点で効果の仕組みやアイテム用のコードは追加していません。

## 次の実装前に検討すること

ユーザーとの合意により、このセッションはダッシュまでで終了し、障害物は別セッションへ引き継ぎます。次の対象は、横からぶつかると止まり、上に着地でき、ジャンプで飛び越えられる固定障害物です。障害物の実装は未着手で、具体的な画像・大きさ・配置は未決定です。通常速度とダッシュの両方で衝突・着地を確認してください。

障害物・アイテムなどを増やす際に、`WalkScene.ts`からキャラクター表示を分離するか検討します。表示部分の分離は未実施の候補です。
