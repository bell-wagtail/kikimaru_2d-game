## 左右に移動し続けられるおさんぽデモ

Phaser＋TypeScript＋Viteで、左右移動・ジャンプに加えて、カメラが横方向へ追従する反復背景を実装しました。左右の画面端による移動制限はありません。左右反転、腕・足のアニメーション、地面への着地、画面操作ボタンを維持しています。

- [反復用背景](../src/kikimaru-assets/assets/backgrounds/tea_river_repeat_x.png) を採用。背景と地面をTileSpriteで反復し、遠景は地面よりゆっくり動きます。
- 読み込み時に背景の左右端を小幅でなめらかに重ね、境界の色差を抑えます。元画像は上書きしていません。
- 反復位置を一周期内に保ち、一定距離ごとに物理座標を移し直して長距離移動での数値の増大を抑えます。描画オブジェクトは移動距離に応じて増えません。
- 「まんなかに戻る」と穴への落下後のリスポーンで、キャラクター・障害物・穴・背景・地面・カメラを開始状態に戻します。
- [stages.ts](../src/stages.ts) から背景キー・移動倍率・継ぎ目の重ね幅を指定できます。シーン開始時のステージ指定にも対応。追加方法は [素材README](../src/kikimaru-assets/README.md) に記載しています。

ステージ選択画面・クリアによる次ステージへの進行は未実装です。依存関係・環境設定の変更はありません。

### ダッシュ速度に応じたスピード線

2026-10-02に、実際の横速度に応じてキャラクター後方へ流れるスピード線を追加しました。

- 徒歩より速くなると短い白い線が出て、加速に応じて長さ・本数・濃さ・流れる速さが増します。減速で弱まり、徒歩速度や横移動の停止で消えます。背景で読み取りやすくするため薄い縁を付けています。
- Shiftとお茶の自動ダッシュで共通です。空中でも現在の横速度に連動し、Shiftを離しても踏切速度が維持されていれば線を維持します。横移動の停止・左右方向転換・壁への衝突停止も反映します。アイテムの円形発光は能力の種類、スピード線は現在の速さを示します。
- 設定の正本は [dashFeedback.ts](../src/dashFeedback.ts) の `DASH_FEEDBACK` です。色・縁の色・不透明度・太さ・最短／最長の長さ・流れる周期・各線の高さ／長さ／位相を変更できます。長さと位置は渡されたキャラクターの幅・高さに合わせ、速さの基準は既存の `PLAYER.speed` / `dashMultiplier` を参照します。
- [SpeedLines.ts](../src/SpeedLines.ts) がひとつのGraphicsを再描画して使います。キャラクターの後ろに描き、パーツや輪郭に依存しません。座標補正後の表示位置へ毎フレーム合わせるため、線の古い座標を残しません。線に物理ボディ・Collider・テクスチャは追加しません。
- フォーカス喪失・手動リセット・落下リスポーン・シーン再起動では線を消去します。編集済みマップ・素材・移動と衝突の処理・依存関係・環境設定に変更はありません。ユーザーが編集したアイテムの明滅設定も維持しています。

### 出題履歴と一巡内の重複防止

2026-10-02に、ユーザーの依頼に沿って [quiz.ts](../src/quiz.ts) の `QuizState` にステージごとの未出題問題を持たせました。正解・不正解にかかわらず、出題時にその一巡の候補から外し、回答後の再開では履歴を残します。問題数よりマーカーが多い場合は、全問を使い切った段階で再び全問を候補に戻し、新しい一巡でも重複なくランダムに出題します。複数の問題がある場合は一巡の最初で直前の問題を避け、境目の連続重複も防ぎます。1問だけの登録でも、その問題を各一巡で出題できます。

### 実装前に確認したリセット・停止・再開方針

- スコアは指定した初期値から開始し、手動の「まんなかに戻る」・落下リスポーン・シーン再起動ですべて初期値に戻します。保存はありません。

- 再開時はゲームのキー・タッチ入力を解除し、接触時の位置と速度から物理更新を再開します。その後は従来の入力処理に戻るため、移動を続けるには押し直します。左右入力がなければ横移動は停止し、空中の縦速度は続きます。
