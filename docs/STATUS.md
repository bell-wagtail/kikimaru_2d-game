# 現在の到達点

更新日：2026-10-01。この文書をセッション間の現在地の正本とし、状態が変わったら本文を更新します。

## 左右に移動し続けられるおさんぽデモ

Phaser＋TypeScript＋Viteで、左右移動・ジャンプに加えて、カメラが横方向へ追従する反復背景を実装しました。左右の画面端による移動制限はありません。左右反転、腕・足のアニメーション、地面への着地、画面操作ボタンを維持しています。

- [反復用背景](../src/kikimaru-assets/assets/backgrounds/tea_river_repeat_x.png) を採用。背景と地面をTileSpriteで反復し、遠景は地面よりゆっくり動きます。
- 読み込み時に背景の左右端を小幅でなめらかに重ね、境界の色差を抑えます。元画像は上書きしていません。
- 反復位置を一周期内に保ち、一定距離ごとに物理座標を移し直して長距離移動での数値の増大を抑えます。描画オブジェクトは移動距離に応じて増えません。
- 「まんなかに戻る」でキャラクター・障害物・背景・地面・カメラを開始状態に戻します。
- [stages.ts](../src/stages.ts) から背景キー・移動倍率・継ぎ目の重ね幅を指定できます。シーン開始時のステージ指定にも対応。追加方法は [素材README](../src/kikimaru-assets/README.md) に記載しています。

ステージ選択画面・クリアによる次ステージへの進行は未実装です。依存関係・環境設定の変更はありません。

## 固定障害物

2026-10-01に、既存の [岩画像](../src/kikimaru-assets/assets/props/rock.png) を使った固定障害物を実装しました。開始位置の左右に、徒歩でも跳び越せる低い岩を配置しています。

- 横から当たると停止し、押し続けてもめり込まず、反対方向へ離れられます。壁で停止すると地上の助走をリセットします。壁際からジャンプすると上面より高くなった時点で横へ進めます。
- 岩の上へ着地・静止でき、再ジャンプと歩いて降りる操作もできます。適切な踏切位置から一回のジャンプで飛び越えられます。
- [stages.ts](../src/stages.ts) の `obstacles` 配列から種類・左上座標・幅・高さを指定できます。現在の種類は `rock` のみ。省略・空配列なら配置しません。負のX座標にも対応し、背景とは別に固定配置します。指定寸法の矩形当たり判定なので、岩の輪郭の斜面に沿った判定ではありません。設定方法は [素材README](../src/kikimaru-assets/README.md) を参照。
- 表示・Phaserの固定ボディ・衝突検索位置を [FixedObstacles.ts](../src/FixedObstacles.ts) にまとめ、プレイヤーと同じ座標補正を適用します。元のステージ座標と累積補正量を分けて管理し、リセットでは補正量を戻して定義位置へ再配置します。移動距離でオブジェクトは増えません。

速度アップアイテム・敵・ダメージ・スコアは実装していません。キャラクター表示の分離も今回の変更には含めていません。

## 確認状況

- 2026-09-30：Shiftダッシュを連続した加減速に変更。地上で左右移動しながらShiftを押すと一定の割合で最高速度へ近づき、離すと徒歩速度へ減速します。途中で押し直すと残った速度から再加速します。2026-10-01に操作感の調整として加速・減速の所要時間をさらに短縮しました。加速・減速時間と速度の正本は [movement.ts](../src/movement.ts) の `PLAYER`。
- ジャンプ中は加速途中・減速途中を含めて踏み切り時の速度を維持し、空中のShift操作では加減速しません。着地から現在のShift状態で加減速を再開します。ジャンプの上向き初速と重力は一定で、高さは横速度に依存しません。同じ高さへの着地・同じ方向への移動なら飛距離は横速度に比例します。歩行アニメーションも現在の速度に応じて連続的に変わります。
- 空中の左右操作による停止・方向転換は従来どおり可能です。地上で移動入力を解除・相殺するか壁で停止すると助走をリセットし、Shift単独では助走をためられません。フォーカス喪失では入力を解除して停止し、地上では助走も解除します。空中でフォーカスを失った場合は再開後も踏み切り速度を保持します。「まんなかに戻る」とシーン再起動では保持速度もリセットします。
- ダッシュはキーボード操作のみ。タッチ専用のダッシュボタンは未実装です。
- 2026-10-01確認：障害物を追加した状態で、mise環境の21テストと型チェックを含むビルドが成功。移動の既存18テストに、障害物定義の検証・静止時の側面接触・共通座標補正後の接触・上面で横移動を妨げないことの検証を追加しました。加速途中の助走を設定時間の半分に修正し、最高速度と異なる速度を検証しています。Phaserチャンクサイズの既存警告は残っています。
- 現在の加減速時間で、Codex内蔵ブラウザのWebGL / Canvas結合テストが両方とも `PASS 全項目完了`。前回未実施だった時間調整後のブラウザ再検証を完了しました。連続加減速・再加速、徒歩／加速途中／最高速度での高さと滞空時間の一致・飛距離の速度比例、空中のShift操作、着地後の加減速、通常／ダッシュ各左右200秒相当の移動、反復位置の連続性、描画数、複数回の座標補正、補正中のジャンプと着地、フォーカス喪失・復帰、リセット、別ステージ再起動を確認しました。長距離の背景検証は障害物のないステージで実行しています。

### 速度アップアイテム（別セッション向け・未実装）

アイテムは今回実装していません。将来は最高速度の引き上げや、移動中に最高速度を維持する効果を追加する想定です。ジャンプ処理でアイテムの種類を判定したり、飛距離へ直接倍率を掛けたりせず、アイテム効果は移動速度側へ反映します。跳躍距離はその結果の実際の踏み切り速度から自然に決まり、ジャンプの高さは一定のままにします。効果時間、倍率、取得・配置方法、停止時や空中での取得時の扱いは次セッションで決めます。現時点で効果の仕組みやアイテム用のコードは追加していません。

## 次の実装前に検討すること

障害物の種類・大きさ・配置を増やす際は、各速度の踏切位置や難易度を検討します。大きな岩は徒歩で一度に飛び越せない場合があります。追加した形状ごとに側面衝突・上への着地・飛び越えを確認してください。

アイテムなどを増やす際に、`WalkScene.ts`からキャラクター表示を分離するか検討します。表示部分の分離は未実施の候補です。新しいワールド配置物もプレイヤー・固定障害物と同じ座標補正へ参加させ、元のステージ位置とローカルな物理座標を分けて管理する必要があります。
