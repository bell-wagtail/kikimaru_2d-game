# 現在の到達点と次の実装依頼

更新日：2026-10-03。現在の状態と次セッションの依頼文の正本です。操作は [RUN](RUN.md)、配置編集は [STAGES](STAGES.md)、検証手順は [CHECKS](CHECKS.md)、設定・実装の正本一覧は [README](../README.md) を参照してください。

## 実装済み

- Phaser＋TypeScript＋Viteのおさんぽデモ。左右移動・Shiftによる加減速・ジャンプ・左右反転・パーツアニメーション・画面操作ボタンに対応しています。空中では踏切時の横速度を保持し、左右入力で停止・方向転換できます。
- 背景と地面は横方向へ反復し、遠景はゆっくり動きます。長距離移動では物理座標を補正し、キャラクター・岩・穴・アイテム・演出・カメラの表示と判定をそろえます。移動に伴って表示や物理ボディを増やしません。
- 岩の側面停止・逆方向への離脱・上面への着地・再ジャンプに対応。穴の側面では停止して落下し、画面下へ落ち切ると開始位置へリスポーンします。穴は [groundTextures.ts](../src/groundTextures.ts) の共通の土・草の色から描画します。
- お茶は効果中の地上移動を最初のフレームから最高速度にし、えびは空中ジャンプを追加できます。同種の再取得は残り時間を更新し、両能力は併用できます。円形発光・取得と終了の短い通知・実速度に応じたスピード線を表示します。
- 魚・みかん・いちごは能力なしの得点アイテムです。能力付きアイテムも取得時に加点します。初期点・上下限・種類別配点・正誤配点の正本は [score.ts](../src/score.ts) の `SCORE_RULES`。現時点ではステージ配置から満点を計算せず、固定上限を使っています。
- クイズは4択・選択肢のランダム化・回答後の正誤と正解・点数変化・一文豆知識に対応。問題文・選択肢・正解・豆知識・出典は [quizData.ts](../src/quizData.ts) の `QUIZ_QUESTIONS` が正本です。
- ステージ内で未出題の問題からランダムに選び、全問を使い切ったら新しい一巡を始めます。複数問題がある場合は一巡の境目の連続重複も防ぎ、問題数よりマーカーが多くても各一巡は重複しません。

## リセット・停止・再開

- 手動の「まんなかに戻る」・落下リスポーン・シーン再起動で、開始位置・背景・カメラ・岩・穴を復元し、入力・助走・能力・スコア・出題履歴・演出を初期化します。取得済みの全アイテムとクイズマーカーも復元します。スコアの保存はありません。
- 各アイテムとクイズマーカーは接触時にその回だけ消費し、同じマーカーでは再挑戦できません。重なるマーカーは1問ずつ出題します。
- クイズと結果の表示中は、物理・アニメーション・能力時間・発光・通知・スピード線・背景をすべて止め、空中でも位置・速度とジャンプ使用状態を保持します。未回答では閉じられません。
- 回答後の「おさんぽを続ける」で入力を解除して再開します。移動を続けるには押し直します。フォーカスを失った間も停止し、復帰だけではクイズを閉じません。

## マップと素材

- 通常起動はユーザー編集済みの [tea-river.txt](../src/stage-maps/tea-river.txt)。配置と演出設定を維持しています。
- 別の [tea-river-trail.txt](../src/stage-maps/tea-river-trail.txt) は、地上の果物、お茶と穴、えびで登る高台の魚・いちご、穴の上の低い橋、序盤・中盤・終盤の平地のクイズを配置した寄り道ステージです。高台の下も歩け、終盤には広い平地があります。`STAGES.teaRiverTrail` / `TRAIL_MAP_GRID` が対応する定義です。
- 開発用の結合テストページで「寄り道ステージで遊ぶ」「高台の手前から遊ぶ」を選べます。回帰テスト用の配置は専用マップを使用し、ユーザー編集済みの配置から独立させています。
- 文字マップは岩・穴・アイテムを指定できます。開始位置はコードの既定値で、スタート・ゴールの記号はまだありません。
- ゴール旗・喜びの頭・きらめきなどの既存素材があります。素材キーと寸法はmanifest、組み込み上の制約は [素材README](../src/kikimaru-assets/README.md) を参照してください。
