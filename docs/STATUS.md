## 実装済み

- Phaser＋TypeScript＋Viteのおさんぽデモ。左右移動・Shiftによる加減速・ジャンプ・左右反転・パーツアニメーション・画面操作ボタンに対応しています。空中では踏切時の横速度を保持し、左右入力で停止・方向転換できます。
- 背景と地面は横方向へ反復し、遠景はゆっくり動きます。長距離移動では物理座標を補正し、キャラクター・岩・穴・アイテム・スタート・ゴール・演出・カメラの表示と判定をそろえます。移動に伴って表示や物理ボディを増やしません。大きな原点のステージは開始・リセット時にも指定スタートを基準として補正します。
- 岩の側面停止・逆方向への離脱・上面への着地・再ジャンプに対応。穴の側面では停止して落下し、画面下へ落ち切ると開始位置へリスポーンします。穴は [groundTextures.ts](../src/groundTextures.ts) の共通の土・草の色から描画します。
- `L/R` で左右の壁をMAPに指定できます。`L` のマス右端と `R` のマス左端が境界で、マス寸法・原点へ追従します。各最大1個・片側指定も可能で、未指定側の自由移動は維持します。薄い点線・短い柱・「ここまで」を表示し、徒歩・ダッシュ・お茶・空中・2段ジャンプ・高速移動でも越えられません。停止中の接触・助走解除・逆方向への離脱、壁際の落下を維持します。壁も累積座標補正・全リセットに参加し、表示と物理境界をそろえます。逆順・身体幅不足・壁に重なる開始／ゴール・外側のアイテム／クイズはエラーにし、満点を取得できない配置を防ぎます。記号と検証は [walls.ts](../src/walls.ts)、表示と物理境界は [StageWalls.ts](../src/StageWalls.ts) が正本です。
- お茶は効果中の地上移動を最初のフレームから最高速度にし、えびは空中ジャンプを追加できます。同種の再取得は残り時間を更新し、両能力は併用できます。円形発光・取得と終了の短い通知・実速度に応じたスピード線を表示します。
- 魚・みかん・いちごは能力なしの得点アイテムです。能力付きアイテムも取得時に加点します。初期点・下限・種類別配点・正誤配点の正本は [score.ts](../src/score.ts) の `SCORE_RULES`。満点は全配置アイテムと全クイズマーカーの正解加点を同ファイルの `stageTotals` で合計し、スコア上限にも使います。同種の複数配置・クイズの複数巡・固定上限を超える配置に対応します。
- クイズは4択・選択肢のランダム化・回答後の正誤と正解・点数変化・一文豆知識に対応。問題文・選択肢・正解・豆知識・出典は [quizData.ts](../src/quizData.ts) の `QUIZ_QUESTIONS` が正本です。
- ステージ内で未出題の問題からランダムに選び、全問を使い切ったら新しい一巡を始めます。複数問題がある場合は一巡の境目の連続重複も防ぎ、問題数よりマーカーが多くても各一巡は重複しません。
- `I` でスタート、`G` でゴールを指定できます。横はマス中央、足元はマス下端で、マス寸法・原点の変更に追従します。各記号は最大1個。床／連続した岩上面で身体の幅全体を支え、身体が岩や画面上端に重ならないことを検証し、不正配置は行・列付きエラーにします。未指定マップや座標ステージの互換性を保ち、任意の座標指定も使えます。
- ゴール接触で取得スコア／MAP満点、正解数／全クイズマーカー数、未回答数を一度だけ確定します。誤答の減点は取得スコアへ反映し、回答数・正答数はその回のプレイで記録します。空MAPはゼロ同士の表示で、割合計算による非数値は出ません。記録の保存はありません。
- 指定スタートの黄色い足元マーク・STARTラベル・きらめき、ゴール旗・GOALラベル・喜びの表情・腕上げ・きらめきを既存素材で表示します。通常の能力発光と併用でき、リセットで通常表情と描画順へ戻します。正本は [endpoints.ts](../src/endpoints.ts)・[stageEndpoints.ts](../src/stageEndpoints.ts)・[playResult.ts](../src/playResult.ts)・[MilestoneOverlay.ts](../src/MilestoneOverlay.ts) です。
- 第2段階のオリジナルBGM・効果音を実装しました。専用の音楽生成ツールはこのセッションにないため、ユーザー承認の上でmise管理のNode.jsによる音合成を採用しました。外部サービス・音声API・サンプル音源・新しい依存は使用していません。ベル・木琴風の旋律、和音、ベース、軽い打楽器のループBGMと、取得・開始・ゴール・クイズ開始・正解・誤答・能力効果終了の効果音があります。定義・音量・曲長・イベント対応は [audioDefinition.ts](../src/audioDefinition.ts)、楽譜・音色・ループ端・WAV書き出しは [audioSynthesis.ts](../src/audioSynthesis.ts)、音源の出自は [音源README](../src/audio-assets/README.md) が正本です。
- 導入済みのPhaserで再生し、初回の実際のユーザー操作後に音声を解放します。読み込み・再生に失敗してもゲームを継続できます。BGMと効果音の独立音量とミュートはゲーム画面の外側にまとめ、ミュートボタンは一つだけです。開始・クイズ・結果のダイアログには追加しません。ダイアログ表示中は外側を操作できないため、音の設定は開く前か閉じた後に変更します。設定はページ内のリセット・再挑戦・シーン再起動で保持し、再読み込みでは既定値に戻ります。正本は [audioSession.ts](../src/audioSession.ts)・[WalkAudio.ts](../src/WalkAudio.ts)・[AudioControls.ts](../src/AudioControls.ts) です。
- ゲーム画面と各操作ボタン・その子要素に、iOS向けの文字選択・長押しメニュー抑制を追加しました。ジャンプの矢印やスコア表示も対象です。クイズ本文・説明文の選択とゲーム外でのページ拡大を維持します。適用範囲の正本は [style.css](../src/style.css)。iOS実機で拡大鏡も含めて解消するかは後日のユーザー確認待ちです。

## リセット・停止・再開

- 手動リセット・落下リスポーン・再挑戦・シーン再起動で、開始位置・背景・カメラ・岩・穴・スタート・ゴールを復元し、入力・助走・能力・スコア・回答数・正答数・出題履歴・結果・演出を初期化します。取得済みの全アイテムとクイズマーカーも復元します。
- 明示的なスタートがあるステージは「おさんぽを始める」で開始し、待機中は入力とゲーム時間を停止します。手動リセット・再挑戦・再起動も開始待機へ戻り、落下リスポーンだけは短い開始演出後に自動再開します。演出時間の正本は `MILESTONE_FEEDBACK`。未指定の既存マップは従来位置で即開始・即復帰します。
- 各アイテムとクイズマーカーは接触時にその回だけ消費し、同じマーカーでは再挑戦できません。重なるマーカーは1問ずつ出題します。
- クイズとその回答結果の表示中は、物理・アニメーション・能力時間・発光・通知・スピード線・背景をすべて止め、空中でも位置・速度とジャンプ使用状態を保持します。未回答では閉じられません。
- 回答後の「おさんぽを続ける」で入力を解除して再開します。移動を続けるには押し直します。フォーカスを失った間も停止し、復帰だけではクイズを閉じません。
- ゴール中も上記の全時間を停止します。「結果を閉じる」またはEscは結果表示だけ閉じ、「結果を見る」で同じ結果を再表示します。「もう一度」または手動リセットで全状態を初期化します。フォーカス復帰だけでは開始待機・ゴールを解除しません。同時接触はアイテム取得→クイズ回答→ゴール確定の順で、重なる全クイズも1問ずつ回答してから結果へ進みます。
- 指定スタートの待機中は無音で、開始操作で開始音とBGMを再生します。未指定マップは最初の操作で音を再生します。クイズ中は回答結果の表示中もBGMを一時停止し、続ける操作で続きから再開します。重なる問題を処理する間はBGMを止めたまま各問題の開始・正誤音を鳴らし、最後にゴールがある場合はそのままBGM停止とゴール音へ進みます。結果を閉じる・再表示・フォーカス復帰ではゴール音を繰り返しません。
- 同時取得・同時効果終了はそれぞれ一つの音へまとめ、各効果音には一つの再生インスタンスを使います。クイズ・ゴールへの移行時は前の効果音を止め、現在の操作に対応する音を優先します。フォーカス喪失・非表示・ミュートではBGMを一時停止して効果音を破棄し、復帰後に効果音を遅延再生しません。各リセットで全音を停止し、再挑戦の開始操作・落下演出後の復帰でBGMを先頭から再生します。リセットによる能力解除では終了音を鳴らしません。シーン終了では音源と入力イベント・UIを破棄し、古い音声解放の非同期処理も無効にします。
