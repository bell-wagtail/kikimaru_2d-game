# 文字マップでステージの配置を編集する

配置の正本は [src/stage-maps/](../src/stage-maps/)、マスの大きさ・原点・ステージとマップの対応は [stages.ts](../src/stages.ts) です。現在のステージは [tea-river.txt](../src/stage-maps/tea-river.txt) を読み込みます。

## 記号と位置

| 記号 | 配置 |
|---|---|
| `.` または半角空白 | 最下行では穴。それより上の行では何も置かない |
| `x` | 岩1個。表示・矩形当たり判定は1マス分 |
| `o` | お茶。効果中は地上移動がShiftなしで即最高速度 |
| `j` | えび。取得すると空中で追加1回ジャンプ |
| `=` | 床。最下行にだけ指定 |

`xxxxx` は5個の岩です。ひとつの画像やボディには結合しません。上の行に置くほど高い位置になり、同じ行の岩は上面の高さがそろいます。空中に置いた岩も固定され、落下しません。

マップは長方形にし、全行の文字数をそろえてください。最下行は床の `=` と穴の `.` / 半角空白で指定します。行を伸ばす場合は、ほかの行にも `.`、最下行にも床か穴の記号を追加します。前後の空行、UTF-8のBOM、Windowsの改行に対応しています。行の途中の空行や未対応の記号はエラーになります。

例えば、最下行を `===...===` にすると、床の間に3マス分の穴ができます。連続する空きマスをひとつの穴として扱います。穴の幅はマス幅に連動し、深さは画面下までです。[groundTextures.ts](../src/groundTextures.ts) で元の地面と同じ色・草の帯・少量の模様を使った縁と土壁を描き、穴の内側へ暗くします。穴を広げると中央部分だけが伸び、左右の土壁は同じ厚さを保ちます。非常に狭い穴では土壁を縮めて収め、穴の外側の地面へはみ出しません。岩を穴の上へ置くこともでき、その岩は固定足場になります。

足元の矩形当たり判定が床から完全に離れると落下します。キャラクターの当たり判定幅より狭い穴はまたげるため、現在のマス設定で落下する穴にする場合は `..` 以上を使ってください。幅を変えた場合は [movement.ts](../src/movement.ts) の `PLAYER.width` と [stages.ts](../src/stages.ts) のマス幅の関係を確認します。飛び越えられる幅は踏切位置・速度にも依存します。

落下中に穴の左右の壁へ当たると横移動が止まり、下へ落ち続けます。押し続けても床の下へ抜けず、反対方向へ離れられます。壁に当たっても床面へ持ち上がりません。えびの効果がある間は落下中も空中ジャンプを1回使えます。画面下へ落ち切ると開始位置へリスポーンし、入力・助走・背景・カメラも開始状態へ戻ります。能力を解除して全アイテムを復元します。リスポーンの位置と高さは従来の開始位置です。開始位置に岩が重ならず、足元に床がある配置にしてください。GameOver・ゴール・残機はありません。

マップの左右端は移動の端にならず、マップの外側には床が続きます。岩・穴・アイテムの配置は横方向へ反復しません。

## 編集する

1. `tea-river.txt` をテキストエディターで開き、上の行の `.` を `x` / `o` / `j` に置き換えたり、最下行の `=` を `.` に置き換えたりして保存します。等幅フォントだと位置を見比べやすくなります。
2. [RUN](RUN.md) の手順で開いた画面を確認します。開発サーバーでは保存したマップが反映され、シーンは開始位置へ戻ります。
3. ジャンプで次の段に届くこと、上面へ着地すること、岩の側面・継ぎ目や穴で意図した動作になることを確認します。検証手順は [CHECKS](CHECKS.md) を参照してください。

マスの幅・高さを変える場合は、`stages.ts` の `STAGE_MAP_GRID.cellWidth` / `cellHeight` を編集します。岩の位置・表示寸法・当たり判定、アイテムの配置と表示枠、穴の位置・幅が一緒に変わります。アイテムは表示枠内に縦横比を保って収め、実際の表示矩形とプレイヤーの物理矩形が重なると取得します。横方向の原点は `originX`、地面の基準は `groundY` です。ゲームの床の高さは `WORLD.ground` なので、ステージの `groundY` もそれを指定してください。

マスを大きくすると段差や距離も広がるため、変更後は改めてジャンプで届くか確認します。ジャンプの高さや速度の設定を、配置変更に合わせて自動で変えることはありません。

## 別のステージを作る

`src/stage-maps/` に別の `.txt` を保存し、`stages.ts` から `?raw` 付きで読み込みます。ステージ定義に `...parseStageMap(読み込んだ文字列, 設定)` を指定すると、`obstacles` / `items` / `holes` が生成されます。ステージごとに設定を変える場合は、`{ ...STAGE_MAP_GRID, cellWidth: 希望の幅, cellHeight: 希望の高さ }` のように渡します。

座標指定による `obstacles` / `items` 配列も使えます。アイテムには `{ id, kind: "tea" または "shrimp", x, y, width, height }` を指定します。既存の `decorations` 配列は互換用に受け付け、同じ座標の取得可能なアイテムとして扱います。`items` と併用する場合もIDを重複させないでください。穴も `holes: [{ id: "pit", x: 左端の座標, width: 穴の幅 }]` で直接指定でき、省略・空配列なら全面が床です。特定の岩だけ寸法などを調整したい場合は、変換結果の配列を加工してステージ定義へ渡せます。文字マップの行・列から生成するIDを使って対象を選びます。マップの行や列を挿入するとIDも変わるため、保存データなどの永続IDとしては扱いません。

直接指定した穴同士が重なる、または端で接している場合は、表示も衝突範囲もつながったひとつの穴として扱います。間に床がない場所へ土の縁だけを描くことはありません。

配置の変換は [stageMap.ts](../src/stageMap.ts)、岩の衝突・座標補正は [FixedObstacles.ts](../src/FixedObstacles.ts)、アイテムの表示・取得・座標補正は [StageItems.ts](../src/StageItems.ts)、穴の表示・床ボディ・座標補正は [StageGround.ts](../src/StageGround.ts) が担当します。物理座標を移し直してもマップから生成した元のステージ座標は変更せず、リセットで定義位置に戻します。

## アイテムの種類・効果を変更する

対応の正本は [items.ts](../src/items.ts) の `ITEM_TYPES` です。`assetKey` はmanifestの素材キー、`symbol` は文字マップの記号、`effect` は能力、`durationSeconds` は効果時間、`name` は取得・終了通知に使う名前です。`glow.color` は発光色、`glow.diameterScale` はキャラクターの大きさに対する円形発光の直径倍率です。持続時間と演出はここから種類ごとに変更できます。素材パス・実寸はmanifestを正とします。

既存能力を使う種類を追加する場合は、素材をmanifestへ登録し、`ITEM_TYPES` へ種類と重複しない記号を追加します。小物PNGは `assets/props/` から解決し、ステージで使う種類だけをPhaserへ読み込みます。新しい能力は [movement.ts](../src/movement.ts) に動作を追加します。取得済み状態と表示は `StageItems`、効果と残り時間は [powerUps.ts](../src/powerUps.ts) に分けています。効果の操作・解除条件は [RUN](RUN.md) を参照してください。

取得・終了の文字表示時間、明滅を速める残り時間、通常時・警告開始時・終了直前の周期、発光の不透明度と中心高さは [feedback.ts](../src/feedback.ts) の `ITEM_FEEDBACK` が正本です。発光は [ItemFeedback.ts](../src/ItemFeedback.ts) がキャラクターの表示位置と渡された幅・高さに合わせて配置します。キャラクター固有の画像や輪郭には依存せず、左右反転でも円を反転させません。
