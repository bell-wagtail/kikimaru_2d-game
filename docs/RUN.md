# おさんぽデモを起動して遊ぶ

前提：[環境準備](SETUP.md)が完了していること。

## 起動・停止

PowerShellでプロジェクトルートに移動して実行します。

```powershell
Set-Location -LiteralPath 'D:\work\029_BellFloworks\11_2d-game'
mise exec -- npm.cmd --cache .npm-cache run dev
```

ターミナルに表示される `Local` のURLをブラウザで開きます。
HTMLファイルのダブルクリックでは起動しません。
停止は、このPowerShellで **Ctrl+C** を押します。毎回の依存再インストールは不要です。

接続先・ポートの正本は [vite.config.js](../vite.config.js) です。現在は同じPCからの接続に限定しています。
別のスマホからの接続設定は、実機確認を行う際に別途決めます。
ポート使用中のエラーが出た場合は、以前起動したサーバーのターミナルを確認してください。

## 操作

| 入力 | 動作 |
|---|---|
| ← / → または A / D | 押している間、左右移動 |
| Shift ＋ 左右移動 | 地上で徐々に加速。Shiftを離すと徐々に減速。左右どちらのShiftでも可 |
| Space（↑ / Wでも可） | 地上からジャンプ。えびの効果中は空中でも追加1回。移動と同時操作可 |
| 画面左下の矢印 / 右下のジャンプ | タッチ・マウス操作 |
| まんなかに戻る | 開始位置に戻り、スコア・能力を初期化して全アイテムを復元 |
| スタートに戻る | `I` 指定ステージでのリセット。指定位置へ戻って開始操作を待つ |

ブラウザをアクティブにして操作してください。キー割り当ての実装は [input.ts](../src/input.ts) です。

ゲーム画面の外側にある「音を消す／音を出す」一つと、「BGM」「効果音」の音量で音声を調整できます。開始・クイズ・結果のダイアログにはミュートボタンを表示しません。ダイアログ表示中は外側を操作できないため、音の設定は開く前か閉じた後に変更します。音量・ミュートはリセット・再挑戦・同じページ内のシーン再起動でも保持し、ページ再読み込みでは既定値へ戻ります。

音声は初回のクリック・タッチ・キー操作後に再生します。指定スタートでは開始ボタンで開始音とBGM、未指定の既存マップでは最初の操作で再生します。音声を利用できない場合もゲームは継続できます。BGMはクイズと回答結果の表示中に一時停止し、続ける操作で同じ位置から再開します。ゴールではBGMを止めてゴール音を一度再生し、結果の再表示では鳴らしません。フォーカス喪失・非表示・ミュートではBGMを一時停止し、効果音は止めて破棄します。

各リセットで残っている音を止めます。再挑戦は開始操作で、落下は開始演出後の復帰時に、BGMを先頭から再生します。リセットによる能力解除では効果終了音を鳴らしません。音源・音量・イベント対応の正本は [audioDefinition.ts](../src/audioDefinition.ts)、素材の出自は [音源README](../src/audio-assets/README.md) を参照してください。

`I` があるステージは「おさんぽを始める」をクリック・タッチ、またはTabで選んでEnter／Spaceで開始します。待機中は入力とゲーム時間が止まり、開始時に入力を解除します。`I` 未指定の既存マップは従来どおり即開始します。指定スタートは黄色い足元マークとSTARTラベル、開始待機と落下からの復帰はきらめきで示します。落下時は指定位置へ戻った後、短い開始演出で自動再開します。

`G` の旗へ触れると、喜びの表情・腕上げ・きらめきとともに結果を一度だけ確定します。取得スコア／MAP満点、クイズ正解数／全マーカー数、未回答数を表示します。満点は全配置アイテムと全クイズを正解した場合の配点から自動計算し、固定上限では打ち切りません。不正解の減点は取得スコアへ反映します。アイテム・クイズがない場合もゼロ同士の表示になります。

ゴール中は物理・アニメーション・能力時間・発光・通知・スピード線・背景を停止します。「結果を閉じる」またはEscで表示だけを閉じ、「結果を見る」で同じ結果を再表示できます。「もう一度」や「スタートに戻る」で入力・能力・助走・得点・回答数・出題履歴・取得状態・演出を初期化し、開始操作を待ちます。結果は保存しません。`G` 未指定なら自由に歩き続けられます。

アイテム・クイズ・ゴールへ同時に触れた場合は、アイテム取得→クイズ回答→ゴール確定の順です。重なるクイズも1問ずつ回答し、「おさんぽを続ける」を押すと次の問題またはゴール結果へ進みます。フォーカス復帰だけでは開始待機・クイズ・ゴールを解除しません。

地上で左右移動しながらShiftを押すと最高速度まで一定の割合で加速し、離すと徒歩速度まで同じように減速します。減速途中で押し直した場合は、その時点の速度から再加速します。加減速の時間・速度・倍率の正本は [movement.ts](../src/movement.ts) の `PLAYER` です。ジャンプ中は、加速途中も含めて踏み切り時の速度を維持し、Shiftによる加減速は着地から再開します。高さは移動速度によらず一定で、同じ高さへ着地して空中操作を変えなければ、速く踏み切るほど遠くへ跳びます。空中の左右操作による停止・方向転換は従来どおり可能です。地上で左右キーを離す・左右同時入力で停止する場合は助走もリセットします。Shift単独で助走をためることはできません。Shiftによるダッシュはキーボード操作のみで、タッチ専用のダッシュボタンはありません。

別ウィンドウへの切り替えやリセット時は、ダッシュを含む押下状態を解除します。戻った際はキーを離してから押し直してください。

左右に進むとカメラが追従し、背景と地面が繰り返し流れます。左右の移動端はありません。「まんなかに戻る」でキャラクター・背景・カメラが開始時の状態に戻ります。

徒歩より速く移動すると、キャラクターの後方に白いスピード線が出ます。実際の横速度に応じて長さ・本数・濃さと流れる速さが増し、減速すると弱まります。Shiftとお茶の自動ダッシュで共通の演出です。ジャンプ中は横速度に応じた線を維持し、左右を切り替えると後方も切り替わります。徒歩速度・横移動の停止・壁への衝突停止・フォーカス喪失・リセット・落下リスポーンで線を消します。色・太さ・長さなどの正本は [dashFeedback.ts](../src/dashFeedback.ts) です。

岩へ横から当たると止まり、ジャンプで上に乗ったり飛び越えたりできます。空中で左右入力を離すと横移動が止まるので、着地点を調整できます。岩の上でもジャンプ・歩行ができ、端から歩くと地面へ降ります。届く高さや踏切位置は配置に応じて調整してください。現在の岩とアイテムの位置は文字マップが正本です。

お茶の効果中は、地上の左右移動がShiftなしで最初のフレームから最高速度になります。地上で移動中に取得した場合も、そのフレームから最高速度です。停止・左右相殺・壁への衝突では従来どおり止まり、移動を再開すると即最高速度になります。タッチ操作でも有効です。スピード線も実速度に応じて最初から最高速度の表示になります。空中で取得・時間切れになっても、そのジャンプの横速度は保持します。着地時にお茶が有効なら即最高速度、効果がなければShiftの状態に応じた従来の加減速へ戻ります。えびを取得すると、ジャンプボタンを離して再度押すことで、通常ジャンプと同じ強さの空中ジャンプを1回使えます。足場から歩いて落ちた場合も使え、地面・岩への着地で回数が回復します。押しっぱなしでは繰り返さず、空中でえびを再取得しても使用回数は回復しません。

両効果は併用できます。持続時間は [items.ts](../src/items.ts) の `ITEM_TYPES` 内の各種類の `durationSeconds` が正本です。同じ種類の別アイテムを取得すると時間を更新し、速度やジャンプ回数を重ねて増やしません。時間切れで能力は終了しますが、取得済みアイテムは消えたままです。フォーカス喪失中はゲームと効果時間が止まります。手動リセット・落下リスポーン・シーン再起動では能力と助走を解除し、アイテムを定義位置に復元します。

効果中はキャラクターの周囲が丸く光ります。お茶は緑、えびは赤で、併用中は内側の緑と外側の赤が重なります。終了が近づくと、その効果の明滅周期が徐々に短くなり、時間切れで光が消えます。取得時は「お茶を取得！」など、時間切れでは「お茶の効果が終了しました」などの短い通知を画面に表示します。複数の通知は並べて表示し、一定時間で消えます。リセット・落下リスポーンでは光と通知を消去し、フォーカス喪失中は明滅と通知時間も停止します。演出設定の正本は [feedback.ts](../src/feedback.ts) です。

草の縁と土の壁に囲まれた暗い部分は穴です。歩いて落ちると、横へ進んでも穴の壁で止まり、そのまま下へ落下して開始位置にリスポーンします。助走・押下状態・背景・カメラも戻るので、キーを離してから押し直してください。踏切位置と速度を調整するとジャンプで対岸へ渡れます。GameOverはありません。`G` を置くとゴールで結果を確定できます。

画面右上にスコアを表示します。能力付きアイテムの取得でも得点が入り、`F` の魚・`M` のみかん・`S` のいちごは能力なしで種類ごとの得点を獲得します。取得時は種類の名前を通知し、果物でも能力時間や発光は追加しません。各配点・初期値・下限と満点計算の正本は [score.ts](../src/score.ts) の `SCORE_RULES` です。手動リセット・落下リスポーン・シーン再起動ですべて初期値へ戻します。スコアの保存はありません。

`Q` のクイズマーカーへ触れると、ステージ内でまだ出題していない問題からランダムに1問を選び、選択肢もランダムに並べます。全問を使い切ったら新しい一巡を始め、その一巡でも同じ問題を繰り返しません。複数の問題があれば、一巡の境目でも直前と同じ問題は続きません。4択をクリック・タッチ、またはTabで選んでEnter／Spaceで回答します。正誤・正解・点数変化と、その問題の一文豆知識を表示し、上下限で配点どおり変化しない場合は実際の増減も表示します。豆知識は正解・不正解のどちらでも表示し、未回答の間は隠します。「おさんぽを続ける」で閉じて再開します。未回答ではEsc・画面外のクリック・「まんなかに戻る」で閉じられません。

クイズとその回答結果の表示中は、キャラクターの物理・アニメーション・能力時間・発光・通知・スピード線・背景を止めます。空中接触でも位置・速度・空中ジャンプ使用状態を保持します。再開時はキー・タッチの入力を解除するため、移動を続ける場合は押し直してください。再開した物理更新から能力時間と動作を進め、左右入力がなければ従来どおり横移動を停止します。フォーカスを戻してもクイズ表示中は再開しません。

魚・果物・クイズマーカーは接触時にその回の取得済み状態となり、消えます。同じマーカーではその回に再挑戦できません。手動リセット・落下リスポーン・シーン再起動ですべて復元し、出題履歴も初期化して再び取得・挑戦できます。別ステージ開始時も新しい出題履歴から始めます。重なるクイズマーカーは1問ずつ出題します。

「まんなかに戻る」で岩・穴・全アイテムの表示もステージの定義位置に戻ります。魚・クイズを含む編集済みの現行マップは維持しています。Agentによる試験配置は専用ステージで行います。`o` / `j` / `F` / `M` / `S` / `Q` と、スタート `I`・ゴール `G` で配置できます。配置の変更方法は [STAGES](STAGES.md) を参照してください。果物は [結合テストページ](CHECKS.md) の「果物を見る」で試せます。

## 寄り道ステージを試す

[CHECKS](CHECKS.md) の開発用ページで「寄り道ステージで遊ぶ」を押すと、果物・能力・クイズを分散した別マップで遊べます。地上を進むルートと、えびの2段ジャンプで高台の魚・いちごを集める寄り道があります。「高台の手前から遊ぶ」でその区間をすぐ試せます。高台は2段目を1段目の頂点付近で使うと届き、登った後は通常ジャンプで上段へ進めます。クイズは序盤・中盤・終盤の平地にあります。

通常の起動時はユーザー編集済みの現行マップです。別マップの配置と設定は [STAGES](STAGES.md) を参照してください。未実装機能と次の依頼文は [STATUS](STATUS.md) にまとめています。
