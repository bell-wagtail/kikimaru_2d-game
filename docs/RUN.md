# おさんぽデモを起動して遊ぶ

前提：[環境準備](SETUP.md)が完了していること。

## 起動・停止

PowerShellでプロジェクトルートに移動して実行します。

```powershell
Set-Location -LiteralPath 'D:\work\029_BellFloworks\11_2d-game'
mise exec -- npm.cmd --cache .npm-cache run dev
```

ターミナルに表示される `Local` のURLをブラウザで開きます。
HTMLファイルのダブルクリックでは起動しません。
停止は、このPowerShellで **Ctrl+C** を押します。毎回の依存再インストールは不要です。

接続先・ポートの正本は [vite.config.js](../vite.config.js) です。現在は同じPCからの接続に限定しています。
別のスマホからの接続設定は、実機確認を行う際に別途決めます。
ポート使用中のエラーが出た場合は、以前起動したサーバーのターミナルを確認してください。

## 操作

| 入力 | 動作 |
|---|---|
| ← / → または A / D | 押している間、左右移動 |
| Shift ＋ 左右移動 | 地上で徐々に加速。Shiftを離すと徐々に減速。左右どちらのShiftでも可 |
| Space（↑ / Wでも可） | 地上からジャンプ。移動と同時操作可 |
| 画面左下の矢印 / 右下のジャンプ | タッチ・マウス操作 |
| まんなかに戻る | 開始位置に戻る |

ブラウザをアクティブにして操作してください。キー割り当ての実装は [input.ts](../src/input.ts) です。

地上で左右移動しながらShiftを押すと最高速度まで一定の割合で加速し、離すと徒歩速度まで同じように減速します。減速途中で押し直した場合は、その時点の速度から再加速します。加減速の時間・速度・倍率の正本は [movement.ts](../src/movement.ts) の `PLAYER` です。ジャンプ中は、加速途中も含めて踏み切り時の速度を維持し、Shiftによる加減速は着地から再開します。高さは移動速度によらず一定で、同じ高さへ着地して空中操作を変えなければ、速く踏み切るほど遠くへ跳びます。空中の左右操作による停止・方向転換は従来どおり可能です。地上で左右キーを離す・左右同時入力で停止する場合は助走もリセットします。Shift単独で助走をためることはできません。ダッシュはキーボード操作のみで、タッチ専用のダッシュボタンはありません。

別ウィンドウへの切り替えやリセット時は、ダッシュを含む押下状態を解除します。戻った際はキーを離してから押し直してください。

左右に進むとカメラが追従し、背景と地面が繰り返し流れます。左右の移動端はありません。「まんなかに戻る」でキャラクター・背景・カメラが開始時の状態に戻ります。

開始位置の左右に低い岩があり、右側は順に高い岩へ登れる配置です。横から当たると止まり、ジャンプで上に乗ったり飛び越えたりできます。右側の低い岩へ着地したら、隣の高い岩へ順にジャンプして横5個の岩へ登れます。空中で左右入力を離すと横移動が止まるので、着地点を調整できます。岩の上でもジャンプ・歩行ができ、端から歩くと地面へ降ります。上段のお茶は仮表示で、取得や効果はありません。

床の黒い部分は穴です。歩いて落ちると画面下へ落下し、開始位置にリスポーンします。助走・押下状態・背景・カメラも戻るので、キーを離してから押し直してください。踏切位置と速度を調整するとジャンプで対岸へ渡れます。GameOverやゴールはありません。

「まんなかに戻る」で岩・穴・お茶の表示もステージの定義位置に戻ります。配置の変更方法は [STAGES](STAGES.md) を参照してください。
