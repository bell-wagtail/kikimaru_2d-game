# ききまる — 2Dゲーム画像素材 v2

「ベルフラワークス」のキャラクター「ききまる」を、スマートフォン対応の横スクロールゲームに使うための素材です。

## 最初に

ZIPを**すべて展開**し、`preview.html` をブラウザで開いてください。外部ライブラリや通信を使わず、画像の組み立て、動作の切り替え、エプロンの色替え、左右反転を確認するための見本です。ゲーム本体ではありません。

`preview.png` は正面・右向き・喜びポーズを組み立てて確認した静止画です。ローカルのCodexには `CODEX_HANDOFF.md` を読ませてください。

ランタイム用は合計28画像。背景以外の27 PNGはアルファ透過あり。元のパーツシートは1254×1254ですが、生成画像は厳密な等間隔グリッドではありません。**元シートを機械的に3等分せず、個別PNGを使用**してください。個別PNGは実際のパーツ範囲を測り、6pxの余白を付けて切り出しました。縮小・再描画はしていません。

## アニメーション方式

これは、完成済みの連番アニメーションではなく、**パーツを組み合わせて動かすカットアウト素材**です。胴体・頭・左右の腕・左右の足・エプロン・胸のマークを一つの親オブジェクトにまとめます。腕と足は同じ画像を複製し、必要に応じて反転します。

- 待機：全体の微小な上下運動。
- 走る：足の前後移動と小さな回転、逆方向の腕振り、胴体の上下運動。
- ジャンプ：移動はゲームの物理処理。見た目に伸縮・腕上げ・着地の煙を追加。
- 喜び：`head_happy` に切り替え、腕を上げ、繰り返し跳ねる。
- 驚き・被弾：`head_surprised` に切り替え、揺れや点滅をゲーム側で追加。

`preview.html` のジャンプは見た目の見本であり、物理計算や当たり判定ではありません。個別の頭はAI生成由来の小さな輪郭差があります。ゲームで表情を切り替えた際に必要なら位置・表示サイズを微調整してください。

## エプロンの色替え

`apron_tint.png` は白系・薄いグレーを基調とする独立画像です。ゲーム側でこのパーツだけに乗算系の色付けをします。初期色の例は `#85a86d`。`badge.png` は別に重ね、クリーム色と紫のマークを保ちます。胴体や親オブジェクト全体に色を付けないでください。

黒に近い色では陰影が見えにくくなります。中程度以上の明るさの色を使うと元の印象が残ります。強化の種類を色だけで伝えず、アイコンや表示文も併用する想定です。

## 地域・ステージ素材の扱い

食べ物は収集アイテムの**候補**で、産地や自治体との対応、強化内容は未確定です。えび・魚は一般化したイラストで、特定の生物種を正確に描いた資料ではありません。地域クイズの根拠として扱わないでください。

背景は静岡県中部を連想させる創作風景で、実在の場所を再現したものではありません。シームレス背景ではないので、そのまま横に反復すると継ぎ目が出ます。画面を覆う背景として固定するか、スクロール範囲を制限してください。背景に地面の当たり判定は含まれません。

足場や操作ボタン、クイズ本文、Resultの文字はゲーム側で描画する想定です。任意サイズに伸ばす地形タイルや完成したステージマップは今回の素材には含みません。

## 確認範囲

28画像の読み込み情報、27画像のアルファ透過、切り出し位置を確認。正面・右向き・喜びポーズを静止画として組み立て、重なりを目視確認しました。`preview.html` は動作見本として同梱していますが、この環境にはブラウザ実行バイナリがないため、ブラウザ上での再生確認は未実施です。スマホ実機の表示と操作はゲーム組み込み時に確認してください。

画像は組み込みの画像生成機能で制作し、切り出し・PNG化・静止画での組み合わせ確認を行いました。ゲーム実装や公開は行っていません。
