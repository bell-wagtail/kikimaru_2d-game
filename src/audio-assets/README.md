# おさんぽ用の音源

このプロジェクト用に旋律・和声・リズムと効果音を作り、数式による音合成で生成したオリジナルWAVです。外部の音源・サンプル・音楽生成サービスは使用していません。歌声はありません。

音源の対応・長さ・相対音量・既定音量は [audioDefinition.ts](../audioDefinition.ts)、楽譜・音色・残響・ループ端処理・PCMの書き出しは [audioSynthesis.ts](../audioSynthesis.ts) が正本です。WAVを直接編集せず、これらの定義から再生成します。生成スクリプトは [generate-audio.mjs](../../scripts/generate-audio.mjs)、実行と検証は [CHECKS](../../docs/CHECKS.md) を参照してください。

BGMはベル・木琴風の旋律、穏やかな和音、ベース、軽い打楽器の小編成です。前の周回の音の余韻をループ先頭へ回し、末尾だけを無音へフェードさせる処理は行いません。効果音は開始・終了端を滑らかにします。PCM形式の詳細は書き出し実装を参照してください。
